**Структура проекта**

Здесь описано, как устроен прототип: где что лежит, какие есть уровни, игровые механики и основные Blueprint'ы. Описание механик и классов сверено с документацией шаблона Stack O Bot от Epic Games: https://dev.epicgames.com/documentation/unreal-engine/stack-o-bot-sample-game-in-unreal-engine

**Об игре**

3D-платформер от третьего лица. Игрок управляет роботом, проходит платформы и решает головоломки на физике. На уровне есть задания: когда игрок выполняет все, открывается портал BP_Portal, и через него уровень заканчивается.

Управление: W, A, S, D - ходьба, мышь - камера, пробел - прыжок, зажатый пробел - реактивный прыжок, E - взять предмет, Esc - пауза.

**Папки в Content**

| Папка | Что там |
| --- | --- |
| StackOBot/ | весь контент игры |
| SharedAssets/ | общая библиотека материалов, подключена как submodule |
| Splash/ | картинки заставки при запуске |
| `__ExternalActors__/` | акторы уровней, каждый в отдельном файле (One File Per Actor) |
| `__ExternalObjects__/` | вспомогательные объекты уровней, тоже хранятся отдельными файлами |
| Collections/, Developers/, DevCom/ | служебные папки редактора и шаблона |

**Уровни (Content/StackOBot/Maps)**

* LVL_MainMenu - главное меню, с него запускается игра
* LVL_StackOBot - главный игровой уровень, сделан на World Partition
* LVL_StackOBot_HLODLayer_Merged - упрощённые модели для дальних частей главного уровня (HLOD), чтобы большой уровень не тормозил
* Lvl_Empty - пустая карта, открывается вместе с редактором и показывает подсказки по шаблону
* SQ_Lvl1_fly - ролик-пролёт по уровню в начале игры
* LevelInstances/ - готовые куски уровня, например летающие острова, из них собран LVL_StackOBot

**Основные Blueprint'ы (Content/StackOBot/Blueprints)**

| Папка | Что там |
| --- | --- |
| Character/ | BP_Bot - робот игрока, в том числе логика захвата предметов |
| Camera/ | BP_CamManager - управление камерой, BP_GameCamVolume - зоны со своей камерой |
| GameElements/ | BP_Portal - портал в конце уровня, BPC_InteractionHandler - взаимодействие с объектами |

| MainMenu/ | главное меню |
| PCG/ | процедурная генерация, например заборов вдоль сплайна (PCG_BP_FenceSpline) |
| SaveGame/ | сохранение |

**Игровые механики**

* ящики, которые робот может брать и ставить друг на друга
* вентиляторы и батуты, которые подбрасывают робота
* летающие платформы и мосты на физических связях
* разрушаемые крыши и платформы, которые появляются заново
* энергетические сферы BP_EnergyOrb, которые можно собирать
* враги, которые ходят, гонятся за игроком и отталкивают его, их можно победить прыжком сверху
* задания: объекты с тегом IsObjective, после выполнения всех открывается портал

**One File Per Actor**

LVL_StackOBot и LVL_MainMenu сделаны на World Partition и уже работают в режиме One File Per Actor: каждый актор уровня лежит отдельным файлом в папке `Content/__ExternalActors__/StackOBot/Maps/`, у каждого уровня своя подпапка. Там же лежат акторы кусков уровня из LevelInstances, всего 3045 файлов и папок. Поэтому, если два человека меняют разные объекты на уровне, они правят разные файлы, и конфликта не будет.

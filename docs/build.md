**Сборка и репозиторий**

Здесь описано, на чём сделан проект, что хранится в репозитории и как его скачать.

**Движок и шаблон**

* Unreal Engine 5.8, у всей команды одинаковая версия
* прототип сделан на шаблоне Stack O Bot от Epic Games (Fab)
* проект только на Blueprint, папки Source с кодом C++ нет, поэтому Visual Studio не нужна
* режим игры по умолчанию: GM_InGame

Карты:

* LVL_MainMenu - главное меню, с него запускается игра
* LVL_StackOBot - главный игровой уровень
* Lvl_Empty - пустая карта, открывается вместе с редактором

**Что лежит в репозитории**

| Файл или папка | Что это | Где хранится |
| --- | --- | --- |
| StackOBot.uproject | файл проекта, им открывается редактор | Git |
| Config/ | настройки проекта, файлы .ini | Git |
| Content/ | ассеты (.uasset), уровни (.umap), картинки заставки (.png) | Git LFS |
| Build/Windows/Application.ico | иконка игры | Git LFS |
| StackOBot.png | превью проекта | Git LFS |
| docs/ | документация проекта | Git |
| .gitignore | что Git не отслеживает | Git |
| .gitattributes | какие файлы идут в LFS | Git |

Текстовые файлы остаются в обычном Git, чтобы было видно, какая строчка поменялась. Бинарные идут в LFS, потому что Git не может показать, что в них изменилось, и хранит каждую их версию целиком.

**Что не лежит в репозитории**

* Binaries/, Intermediate/, Saved/, DerivedDataCache/ - движок создаёт их сам при открытии проекта
* Build/ - файлы для сборки под Android и Windows, кроме иконки Application.ico
* Builds/ - собранная игра, она будет выкладываться в Releases
* Content/FirstGameInUE5_Source.zip - архив с исходниками туториала, движок его не использует

**Размеры**

| Что | Размер |
| --- | --- |
| папка Content на диске | 1043 МБ |
| из неё архив FirstGameInUE5_Source.zip, исключён | 283 МБ |
| ушло в Git LFS (1966 файлов) | 761 МБ |
| сам Git-репозиторий после первого коммита | около 400 КБ |

В LFS ушли 1930 файлов .uasset, 32 .umap, 3 .png и 1 .ico. В самом Git вместо них лежат только маленькие указатели, поэтому репозиторий весит меньше мегабайта.

**Как склонировать и открыть**

```
git lfs install
git clone https://github.com/Tolaynjch86/OPD_Lab4_UnrealEngine.git
```

После клонирования открыть StackOBot.uproject. Первый запуск долгий, движок компилирует шейдеры.

**Хуки**

После клонирования один раз выполнить в корне репозитория:

```
powershell -ExecutionPolicy Bypass -File setup.ps1
```

Скрипт подключает хук pre-commit из папки .githooks. Хук не даёт закоммитить файлы из Saved, Intermediate, Binaries, DerivedDataCache и .vs, а также файлы больше 50 МБ, которые не идут через LFS. Проверить, что хук подключён: команда git config --get core.hooksPath должна вывести .githooks.
